- (constraint) Cleaning: quarantine only provably invalid rows with reason codes; flag doubtful rows; never delete silently
- (constraint) ADMIN_CLOSURE rows count as requests but are excluded from durations and completions per week
- (constraint) Durations reported as median and 90th percentile, never mean
- (constraint) All timestamps in SAST (Africa/Johannesburg); weeks start Monday
- (constraint) Power BI Desktop on Windows, model saved as PBIP/TMDL in git; no Power BI Service account, so no publish-to-web, refresh schedule or RLS
- (constraint) Raw and processed data are not committed; the pipeline regenerates them
